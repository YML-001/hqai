# 后勤智能助手原型交付说明

打开根目录 index.html 即可进入演示。服务配置联动请使用同一浏览器内的本地预览地址。

## 页面与端口

- 学生：student/pc、student/mobile
- 教职工与指定提醒接收人：staff/pc、staff/mobile
- 游客：visitor/pc、visitor/mobile
- 管理端：admin/pc
- 角色权限、业务流程与功能说明：guide

每个页面均有内联样式；不同内容与关键状态使用独立HTML文件。

## 导航与后台配置

- 对话记录从智能问答页内的按钮进入；本人消息通知从同页铃铛进入。左侧及手机底部不设置这两个一级菜单。
- 历史、通知列表及详情保留独立HTML，均可返回智能问答；学生新增本人消息列表、未读、详情及空状态。
- 游客无需登录即可提问、看来源与功能列表；点击具体服务或提问需要本人信息时，提示登录并保留原问题和服务意图。
- 首页提供学生、教职工、游客各自的移动端与PC端，以及管理员共七个入口；学生与教职工阅读状态分别保存。
- 服务内容管理可维护卡片名称、图标、简介、分类、角标、排序、办理说明、步骤、适用对象、终端地址、按钮及提示文案。
- 通用展示配置可维护服务大厅与服务指引的标题、说明，以及服务搜索提示。
- 服务内容经双端预览、确认发布后，在当前浏览器同源前台页面同步演示；标准问答及引用仍在知识库管理中维护。

## 演示边界

本项目为可点击的设计原型。统一身份认证、大模型、学校语音、ITS及共享数据均未连接真实服务。服务配置和表单保存在当前浏览器；服务内容与通用展示支持同源页面联动，其他静态状态页和统计仍使用样例。正式系统需补充后端鉴权、持久化、版本审计、检索、任务调度、回执及幂等处理。

语音录入为无麦克风演示；数字人嘴型配合浏览器播报模拟。站内会议通知与ITS独立记录，未接真实消息服务。校园氛围图片来自Unsplash；业务二维码编码正式服务地址；校内送餐使用用户提供的微信小程序码，移动端地址可在后台配置。

## 推荐演示路径

1. 后台 → 服务内容管理 → 配置服务 → 修改卡片与办理步骤 → 双端预览 → 确认发布 → 前台服务大厅与指引查看更新。
2. 后台 → 服务内容管理 → 通用展示配置 → 修改页头和搜索提示 → 预览确认 → 两端查看更新。
3. 学生电脑端 → 智能问答 → 对话记录按钮 → 历史列表 → 返回智能问答。
4. 教职工智能问答 → 消息铃铛 → 未读通知 → 详情 → 本人会议 → 返回问答观察未读数。
5. 学生电脑端首页 → 水电问答 → 来源原文 → 水电缴费 → 手机扫码。
6. 学生移动端 → 网上报修指引 → 跳转确认 → 官方服务。
7. 后台 → 知识库 → 上传文件 → 解析预览 → 确认入库 → 关联来源文件。
8. 后台 → 知识库 → 编辑 → 预览确认 → 上线 → 下线确认。
9. 后台 → 新建会议 → 预览确认 → 详情 → 取消。
10. 后台 → 提醒记录 → 部分失败 → 仅失败对象重试。

11. 智能问答 → 校内送餐 → 电脑端微信扫码，移动端点击打开小程序；后台可更换小程序码、配置移动端地址。未配置地址时先进入跳转演示页，备用口令可复制到微信。

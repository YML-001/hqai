## 发现并处理的问题

- 上轮“我的”页主要沿用旧卡片结构，本轮按独立设计重组。
- 教职工大厅曾沿用学生双列结构，本轮按稿改为单列。
- 部分教职工从属页面背景尺寸继承错误，出现重复图案，已修正铺放范围。
- 问答头像曾显示机器人身体，本轮按头部片段裁切。
- 反馈和语音确认页的底部操作区拥挤，已移除从属页底栏并调整按钮位置。
- 后台手机服务预览仍呈现旧版指引，本轮复用与前台相同的重排和视觉样式。
- 全量检查发现游客隐私页返回了不存在的个人中心地址，已改为游客首页。
- 重新组织知识预览与详情时，保留了来源文件脚本、绑定点和原有提交地址，并验证关联文件仍可打开。

## 实际操作复核

| 路径 | 结果 |
| --- | --- |
| 学生“我的”→消息→详情 | 成功进入；自动标为本人已读，通知入口计数同步 |
| 智能问答→缴费指引→前往办理 | 成功显示办理信息及原系统地址 |
| 教职工会议→最新安排、取消详情 | 时间、地点与取消状态分别保留；返回本人会议路径正确 |
| 回答反馈→提交 | 进入原有反馈成功页 |
| 语音演示→结束识别→确认发送 | 进入对应问答结果；未请求麦克风权限 |
| 游客公开提问→本人记录查询 | 公开提问直接回答，查询本人信息时才提示登录 |
| 后台送餐配置→双端预览→发布 | 电脑和手机都读取更新后的简介；电脑显示原小程序码，手机进入跳转演示 |
| 上传TXT→解析→确认入库→来源列表 | 文件正文、片段与入库状态正常；重复上传有原有中文提示 |
| 知识编辑→关联文件→预览→确认上线→详情 | 原字段正常保留，未确认不能上线，详情可打开关联来源文件 |
| 知识详情→下线确认→填写原因→提交 | 空原因时按钮禁用，填写后进入原有下线状态页并保留原因 |

本轮使用演示文件与演示配置，结束后通过原型的“重置本地演示数据”入口清理。实际学校接口、检索服务、ITS送达和微信唤起未纳入本轮验证。

# 中南大学后勤智能助手原型

面向学生、教职工、游客和管理员的多端网页交互原型，共包含310个独立HTML页面。

[公开预览](https://yml-001.github.io/hqai/)

## 入口与功能

首页提供七个入口：学生移动端、学生PC端、教职工移动端、教职工PC端、游客移动端、游客PC端及管理员。

- 游客可直接提问、查阅公开知识和浏览功能，使用具体服务或请求个人信息时再提示登录。
- 师生问答页内提供对话记录与消息铃铛，学生服务消息和教职工会议通知分别保存阅读状态。
- 服务大厅与完整办理指引支持后台配置、双端预览和确认发布。
- 校内送餐支持电脑端微信扫码、移动端点击小程序地址跳转；后台可上传或更换小程序码、配置移动地址与备用分享口令。正式地址待后续提供，未配置时展示独立跳转演示页。
- 知识库支持文件上传、正文解析、来源关联及发布状态演示。
- 提供语音输入样式、可模拟说话的数字人、会议日程和双通道提醒演示。

## 文件结构

| 目录或文件                 | 用途                                            |
| -------------------------- | ----------------------------------------------- |
| `index.html`               | 角色与终端导航                                  |
| `student/`                 | 学生电脑端及移动端                              |
| `staff/`                   | 教职工电脑端及移动端                            |
| `visitor/`                 | 游客电脑端及移动端                              |
| `admin/pc/`                | 后台管理端                                      |
| `guide/`                   | 权限矩阵、业务流程和功能说明                    |
| `assets/`                  | 数字人、二维码及本地依赖素材                    |
| `tools/`                   | 原型页面生成源码、服务数据、Figma主题和交互脚本 |
| `文档/01-需求资料/`        | 建设实施方案、后勤知识库与服务链接原始文档      |
| `文档/02-交付与验收/`      | 交付说明、检查记录与页面清单                    |
| `交付包/`                  | 完整HTML原型压缩包                              |
| `previews/设计参考/`       | 原始设计参考截图                                |
| `previews/早期页面截图/`   | 早期页面效果截图                                |
| `previews/` 下其他专题目录 | 配置、导航、通知与校内送餐等专项验证截图        |

直接打开根目录的 `index.html` 开始演示。各角色网页与素材保持现有目录，已有网页链接和公开预览地址可继续使用。

原始需求资料、截图与交付压缩包仅在本地保留，不随公开仓库上传。整理时保留原文件名；服务数据源码已归入 `tools/prototype_data.py`。

## 设计稿与视觉维护

本轮界面采用用户提供的[中南大学智慧后勤AI助手设计稿](https://www.figma.com/design/MUNvl94py8SASSMrpn4pPI/?node-id=0-1)。电脑端、师生移动端和管理端分别使用对应设计；游客与独立状态页沿用同端公共视觉规范，保留原有角色与办理逻辑。

- `tools/figma_theme.py`：将原有内容组织为设计稿布局，保留表单及业务交互挂载点。
- `tools/figma_theme.css`：多端视觉样式，由生成器内联到每个HTML页面。
- `tools/figma_theme.js`：后台菜单筛选及服务大厅搜索按钮。
- `tools/figma_deep.py`、`tools/figma_deep.css`、`tools/figma_deep.js`：按移动端各内页设计重排身份、消息、问答、服务指引、会议和账户展示。
- `tools/figma_kb.py`、`tools/figma_kb.css`：知识编辑、发布预览、详情、上传、空态与下线确认的独立设计适配。
- `tools/figma_assets.json`：原始设计素材与本地文件映射，素材放在`assets/figma/`。
- `文档/02-交付与验收/Figma设计映射说明.md`：设计节点与页面对应关系。
- `文档/02-交付与验收/内页设计复核记录.md`：内页修正、实际操作路径与验证边界。

## 本地预览

在项目根目录运行：

```bash
python3 -m http.server 8796
```

随后打开 `http://127.0.0.1:8796/`。通过同一站点访问可演示后台配置和前台页面联动。

修改页面生成源码后，可重新生成原型：

```bash
python3 tools/build_prototype.py
```

## 发布方式

使用GitHub Pages，从`main`分支的根目录发布；`.nojekyll`用于直接发布静态文件。

## 原型范围

登录、问答、语音识别、个人业务数据及学校通知通道均为前端演示，未连接真实学校接口。数字人通过浏览器语音合成与动作模拟播报。配置、草稿和消息阅读状态保存在当前浏览器，不跨设备共享。

真实报修、缴费和查询通过已配置的原业务平台办理。字体、图标、Tailwind和Unsplash图片等部分资源需要网络访问。原始需求文档、参考截图与本地交付压缩包保留在本地。
